# Brims Autos

A responsive automotive dealership website concept designed for showcasing vehicles and automotive services.

## Features
- Vehicle showcase
- Dealership-style layout
- Responsive navigation
- Interactive frontend
- Mobile-friendly design

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Getting Started
Clone the repository and open `index.html` in a browser.
